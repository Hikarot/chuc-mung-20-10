# 🌸 Chúc Mừng Ngày Phụ Nữ Việt Nam 20/10

Trang web thiệp chúc mừng tương tác nhân ngày Phụ nữ Việt Nam 20/10 với giao diện lung linh, hiệu ứng cánh hoa rơi, pháo hoa confetti, hộp quà bất ngờ và các lời chúc ý nghĩa.

## ✨ Tính năng nổi bật
- 🌺 **Hiệu ứng cánh hoa rơi** mềm mại và pháo hoa rực rỡ.
- 🎁 **Hộp quà bí mật** & mở khóa thông điệp yêu thương.
- 💌 **Thiệp chúc mừng** tương tác và giao diện lãng mạn.
- 📱 **Tương thích hoàn hảo** trên cả máy tính và điện thoại di động (Responsive).

## 🚀 Trải nghiệm trực tiếp
Mở file `index.html` trực tiếp trên trình duyệt hoặc sử dụng [GitHub Pages](https://hikarot.github.io/chuc-mung-20-10/).
