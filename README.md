# 🌸 Chúc Mừng Ngày Phụ Nữ Việt Nam 20/10

Trang web thiệp chúc mừng tương tác nhân ngày Phụ nữ Việt Nam 20/10 với giao diện lung linh, hiệu ứng cánh hoa rơi, pháo hoa confetti, hộp quà bất ngờ và các lời chúc ý nghĩa.

## ✨ Tính năng nổi bật
- 🌺 **Hiệu ứng cánh hoa rơi**: Canvas mượt mà, lãng mạn.
- 🎁 **Màn hình bất ngờ & Thử thách nhận quà**: Nút trêu đùa chạy trốn và tương tác chạm hoa hồng nạp năng lượng hạnh phúc.
- 🎟️ **Rút lộc & Xin vía 20/10**: Các thẻ vía may mắn tương tác kèm pháo hoa.
- 🌷 **Góc tôn vinh phái đẹp**: Bộ ảnh phong cách Polaroid vintage bắt mắt.
- 💌 **Tâm thư 20/10**: Hiệu ứng gõ chữ tự động (Typewriter) đầy cảm xúc.
- 🎶 **Trình phát nhạc tích hợp**: Hỗ trợ Web Audio API tự tạo giai điệu du dương hoặc dùng file MP3 tùy chọn.
- 📱 **Tương thích hoàn hảo**: Chuẩn responsive trên cả máy tính lẫn điện thoại di động.

## 📁 Cấu trúc dự án
Dự án được phân chia rõ ràng theo từng file và chức năng chuyên biệt:

```text
├── css/
│   ├── base.css          # Thiết lập màu sắc, biến chung, canvas và layout nền
│   ├── components.css    # Thanh menu điều hướng và nút đĩa nhạc xoay
│   ├── intro.css         # Giao diện màn hình mở đầu (quét nhan sắc, hoa hồng bung nở)
│   ├── sections.css      # Chi tiết các khối (Hero, Thẻ xin vía, Gallery Polaroid, Bức thư)
│   └── style.css         # File gộp các style
├── js/
│   ├── config.js         # Toàn bộ cấu hình nội dung, danh sách voucher, ảnh, nhạc, lời chúc
│   ├── petals.js         # Xử lý hiệu ứng canvas cánh hoa đào rơi tự nhiên
│   ├── audio.js          # Trình phát nhạc và xử lý âm thanh Web Audio / MP3
│   ├── main.js           # Render thẻ xin vía, gallery, hiệu ứng gõ chữ & pháo hoa
│   └── intro.js          # Xử lý logic tương tác màn hình bất ngờ mở đầu
├── index.html            # Cấu trúc HTML chính
└── README.md             # Tài liệu giới thiệu dự án
```
